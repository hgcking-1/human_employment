고객사 로고 넣는 방법
=========================

이 폴더(images/logos)에는 지금 임시 그림 12개가 들어 있습니다.
이것을 실제 고객사 로고로 하나씩 바꿔 넣으시면 됩니다.


[ 1단계 · 파일 바꿔 넣기 ]

  준비한 로고 그림의 이름을 아래처럼 바꿔서 이 폴더에 덮어씁니다.

    logo-01.png   ← 가장 최근 고객사
    logo-02.png
    logo-03.png
        :
    logo-12.png   ← 가장 오래된 고객사

  홈페이지에는 logo-01 부터 순서대로, 왼쪽 위에서 오른쪽으로 표시됩니다.
  즉 파일 번호 순서가 그대로 최신순이 됩니다.


[ 2단계 · 회사 이름 넣기 ]

  index.html 을 메모장으로 열고 아래와 같은 줄을 찾습니다.

    <img src="images/logos/logo-01.png" alt="고객사 01">

  alt="고객사 01" 부분의 글자를 실제 회사 이름으로 바꿉니다.

    <img src="images/logos/logo-01.png" alt="○○산업">

  이 글자는 그림이 안 뜰 때 대신 보이고, 검색에도 사용됩니다.
  꼭 바꿔주시는 것이 좋습니다.


[ 로고 그림 만들 때 ]

  · 파일 형식 : PNG 를 권장합니다 (배경이 투명하게 처리됩니다)
  · 크기      : 가로 240~480px 정도면 충분합니다
  · 배경      : 흰색 또는 투명
  · JPG 를 쓰려면 파일 이름을 logo-01.jpg 로 하고,
    index.html 안의 logo-01.png 도 logo-01.jpg 로 함께 고쳐야 합니다


[ 개수를 늘리거나 줄이려면 ]

  index.html 에서 아래 한 줄이 로고 한 칸입니다.

    <div class="col col-6"><div class="client"><img src="images/logos/logo-01.png" alt="고객사 01"></div></div>

  · 늘리기 : 이 줄을 복사해 아래에 붙여넣고 번호만 바꿉니다 (logo-13, logo-14 ...)
  · 줄이기 : 필요 없는 줄을 통째로 지웁니다
  · 순서바꾸기 : 줄을 통째로 잘라서 원하는 위치에 붙여넣습니다

  한 줄에 6칸씩 표시되며, 휴대폰에서는 자동으로 2칸씩 표시됩니다.


[ 주의 ]

  이 images 폴더는 HTML 파일들과 같은 위치에 있어야 합니다.
  index.html 만 따로 옮기면 로고가 보이지 않습니다.
  (글과 디자인은 그래도 정상적으로 나옵니다)
