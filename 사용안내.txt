휴먼엠에스 홈페이지 — 사용 안내
=====================================

[ 파일 구성 ]
  index.html          홈
  company.html        회사소개
  business.html       사업소개
  contact.html        CONTACT (문의)
  images/logos/       고객사 로고 그림 (지금은 임시 그림 12개)

디자인(CSS)과 동작(자바스크립트)이 각 HTML 파일 안에 모두 들어 있습니다.
따라서 파일 하나만 따로 열어도 화면이 그대로 나옵니다.

단, 고객사 로고는 그림 파일이라 images 폴더가 함께 있어야 보입니다.
폴더째로 옮기시면 문제 없습니다.
로고 바꾸는 방법은 images/logos/로고넣는법.txt 를 봐주세요.


[ 열어보는 방법 ]
  index.html 을 더블클릭하면 기본 브라우저에서 열립니다.
  다른 브라우저로 보고 싶으면 파일을 오른쪽 클릭 → 연결 프로그램 에서 고르세요.


[ 확인된 동작 환경 ]
  - 크롬, 엣지, 웨일, 파이어폭스, 사파리
  - 인터넷 익스플로러 11
  - 안드로이드 / 아이폰 모바일 브라우저

  익스플로러에서도 깨지지 않도록 다음을 지켰습니다.
  · CSS 변수(var), CSS Grid, flex, clamp 등 익스플로러가 못 읽는 문법을 쓰지 않음
  · 자바스크립트는 옛 문법(ES5)만 사용
  · 자바스크립트가 막혀 있어도 글과 화면은 그대로 보이도록 구성


[ 내용 고치는 방법 ]
  1) 파일을 오른쪽 클릭 → 연결 프로그램 → 메모장 을 선택합니다.
  2) 화면에 보이는 글자를 찾아 그대로 고친 뒤 저장합니다.
  3) 브라우저에서 F5(새로고침)를 누르면 바뀐 내용이 나옵니다.

  ※ < > 로 둘러싸인 부분은 건드리지 마시고, 그 사이의 글자만 바꾸세요.
  ※ 고치기 전에 파일을 복사해 두시면 안전합니다.


[ 아직 채워지지 않은 곳 ]
  파일 안에서 ▼ 표시를 찾으면 바로 그 자리입니다.

  · index.html  — 채용 공고 4칸 (알바몬 공고 주소, 제목, 지역, 조건)
  · index.html  — 숫자 4개 (매출액, 사업실적 건수 등 실제 수치)
  · images/logos/ — 고객사 로고 그림 (임시 그림을 실제 로고로 교체)
  · company.html — 연혁 (연도별 주요 이력)
  · contact.html — 지도 (네이버/카카오 지도 코드 붙여넣는 자리)


[ 인터넷에 올리려면 ]
  이 4개 파일을 웹호스팅 서버나 워드프레스의 파일 관리자에 올리면 됩니다.
  첫 화면으로 쓰려면 index.html 이 최상위 폴더에 있어야 합니다.
